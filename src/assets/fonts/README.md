- Fraunces (optical size 9–144, weight 600–800): https://fonts.gstatic.com/s/fraunces/v38/6NU78FyLNQOQZAnv9bYEvDiIdE9Ea92uemAk_WBq8U_9v0c2Wa0KxC9TeP2Xz5c.woff2
- Source Sans 3 (variable weight): https://fonts.gstatic.com/s/sourcesans3/v19/nwpStKy2OAdR1K-IwhWudF-R3w8aZejf5Hc.woff2

Both use the SIL Open Font License; the corresponding copyright and license files are included alongside the fonts. Vite fingerprints these assets and the shared layout preloads the same URLs used by the stylesheet. Characters outside the Latin subsets use the existing system-font fallbacks.
